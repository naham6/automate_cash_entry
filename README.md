
A simple web app project for recording cash collections by person and collection type.

## About the Project

Made this project to practise Google Apps Script and build a simple form for entering cash collection amounts.

The idea is to make it easier to record collections by selecting a date, collection type, and salesperson, then entering the amount.

## What Used

- **HTML** – to build the webpage and form
- **CSS** – to style the page and make it responsive
- **JavaScript** – to handle form interactions and validation
- **Google Apps Script** – for the backend and Google Sheets integration
- **Google Sheets** – intended for storing collection data

## Features

- Access-code entry
- Date, collection type, and salesperson selection
- Amount entry and validation
- Options to add to or replace an existing amount
- Basic submission logging for tracking changes. (Optional)

## Current Status

The project is still a work in progress. The webpage can be used as a preview. The Google Apps Script backend and Google Sheets connection need to be configured and deployed before the full app can work.


## Purpose

The goal is to make cash collection entry simpler and more organized, while working on automation with Google Apps Script.
